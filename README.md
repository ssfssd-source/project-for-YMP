Консольное приложение на Python для шифрования, расшифрования и автоматического взлома текста, зашифрованного шифром Цезаря. Программа работает с кириллицей (русский язык) и сохраняет регистр символов, знаки препинания и цифры.

## Функционал
1. **Шифрование**: сдвиг букв русского алфавита на заданный пользователем ключ.
2. **Расшифрование**: обратный сдвиг текста при известном ключе.
3. **Авто-взлом**: автоматический подбор ключа без его предварительного знания. Реализован на основе **частотного анализа** с использованием метрики среднеквадратичного отклонения (метод наименьших квадратов) от эталонных частот букв в русском языке.
4. **Аналитика**: при авто-взломе программа выводит топ-3 наиболее вероятных сдвига с коэффициентами отклонения.
5. **Отказоустойчивость**: валидация пользовательского ввода (программа защищена от ввода пустых строк, букв вместо чисел и некорректных пунктов меню).

## Требования
* Python 3.x
